COBOL Currency Converter
    A currency converter written in COBOL.

How to Run
    1. Open 'CONVERSOR-MONEDAS.cbl' in OpenCobolIDE
    2. Compile with F8
    3. Run with F9

Features
    - Convert EUR, USD, GBP
    - Menu with loop
    - Input validation
    - Formatted output
